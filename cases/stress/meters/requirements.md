# Контроль показаний счётчиков энергоресурсов

## 1. Контекст
Обходчики снимают показания счётчиков электроэнергии на объектах компании. Ошибки ввода и аномальные скачки потребления обнаруживаются только при выставлении счетов.

## 2. Цель
Сервис приёма показаний с карты объектов, проверкой аномалий и отчётами по потреблению.

## 3. Функциональные требования
Система должна:
- загрузить объекты и счётчики из приложенного файла;
- показывать объекты на карте;
- принимать показания счётчика от обходчика (значение, дата, фото);
- не принимать показание меньше предыдущего;
- отмечать аномалию, если потребление за период больше среднего в 3 раза, и уведомлять энергетика;
- рассчитывать потребление за месяц по объекту;
- показывать историю показаний счётчика.

## 4. Источники данных
- файл objects.json со списком объектов и их счётчиков (координаты объекта, серийные номера счётчиков).

## 5. Ожидаемые компоненты
- мобильное приложение обходчика на Kotlin (карта объектов, ввод показаний);
- web-интерфейс энергетика на Angular;
- backend на C#, PostgreSQL/PostGIS, Kafka;
- Docker, тестовые данные, тесты, CI/CD, документация.

## 6. Демонстрационный сценарий
1) обходчик выбирает объект на карте и вводит показание счётчика;
2) показание меньше предыдущего отклоняется;
3) обходчик вводит показание с резким скачком потребления;
4) система фиксирует аномалию и уведомляет энергетика;
5) энергетик видит потребление объекта за месяц и историю показаний.
