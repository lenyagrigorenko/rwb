# Запись пациентов к врачам поликлиники

## 1. Контекст
Пациенты записываются к врачам по телефону, регистратура перегружена, пациенты забывают о приёме и не приходят.

## 2. Цель
Прототип сервиса онлайн-записи: мобильное приложение для пациента и веб-кабинет для регистратуры и врачей.

## 3. Функциональные требования
Система должна:
- вести справочник врачей (ФИО, специальность, кабинет);
- формировать расписание приёма врача слотами по 20 минут;
- позволять пациенту найти свободный слот по специальности и дате;
- записывать пациента на слот (полис ОМС — 16 цифр, телефон в формате +7XXXXXXXXXX);
- не допускать двойной записи на один слот;
- позволять пациенту отменить запись не позднее чем за 2 часа до приёма;
- напоминать пациенту о приёме за 2 часа;
- позволять врачу отмечать приём как состоявшийся или неявку;
- показывать регистратуре загрузку врачей на день.

## 4. Ожидаемые компоненты
- мобильное приложение на Kotlin для пациента (список записей, запись на приём, отмена, уведомления);
- web-интерфейс на Angular для регистратуры и врачей;
- backend на C# / ASP.NET Core, PostgreSQL;
- события записи и напоминаний;
- Docker, тестовые данные, автотесты, CI/CD, документация.

## 5. Демонстрационный сценарий
1) регистратор формирует расписание врача-терапевта на завтра;
2) пациент находит свободный слот и записывается;
3) попытка второго пациента записаться на тот же слот отклоняется;
4) за 2 часа до приёма пациент получает напоминание;
5) врач отмечает приём как состоявшийся;
6) регистратура видит загрузку врача.
